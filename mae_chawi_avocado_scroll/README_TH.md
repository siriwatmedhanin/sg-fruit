# Mae Chawi — Avocado Scroll Story (V1)

ต้นแบบเว็บไซต์ร้านไร่แม่ฉวีที่เขียนจากไอเดียของผู้ใช้: **จากต้นอะโวคาโด → ร่วงลงบนเขียงและมีดผ่า → อะโวคาโดสไลซ์เทลงจานสลัด**

## ข้อเท็จจริงจากคลิปอ้างอิง

วิดีโอที่แนบเป็นการถ่ายเว็บไซต์บนแล็ปท็อป เริ่มจากมะเขือเทศห้อยบนต้น มีการเปลี่ยนเป็นชาม/ซอสและพิซซ่า ก่อนพิซซ่าเข้าเตาอบ ขณะที่ฉากเขียง มือผ่าอะโวคาโด และสลัด เป็น **การออกแบบใหม่** ตามโจทย์ ไม่ได้ปรากฏในคลิปต้นฉบับ

## เปิดเว็บทันที

- ดับเบิลคลิก `index.html` เปิดด้วย Chrome / Edge ได้ (ไม่มี CDN ไม่มี dependency)
- หรือใช้ terminal ในโฟลเดอร์นี้: `python -m http.server 8090` แล้วเปิด `http://localhost:8090`
- เลื่อนลงช้า ๆ เพื่อดูฉากที่ 1, 2, 3; คลิกเมนูบนสุดเพื่อข้ามฉาก
- ไฟล์ SVG ถูกวาดอยู่ **ภายใน HTML ทั้งหมด** จึงไม่ต้องมีไฟล์ภาพแยกในขั้นต้น

## สิ่งที่ V1 ทำแล้ว

- Sticky storytelling ขณะเลื่อนหน้าเว็บ พร้อมการย้อนกลับตาม Scroll
- ฉาก 1: ผลอะโวคาโดร่วงจากกิ่ง
- ฉาก 2: ผลอะโวคาโดร่วงลงเขียง มือถือมีดเคลื่อนลงมา และผลเปลี่ยนเป็นสองซีก
- ฉาก 3: อะโวคาโดสไลซ์เคลื่อนจากชามลงไปที่จานสลัด
- responsive สำหรับมือถือ, ระบบลดการเคลื่อนไหว (`prefers-reduced-motion`)
- ตัวอย่างสินค้าและปุ่มสอบถามสินค้า (ยังไม่ใช่ระบบชำระเงินจริง)

**ข้อจำกัดของ V1:** ภาพเป็นภาพวาด SVG ที่ใช้ทดสอบจังหวะ ไม่ใช่ภาพถ่ายหรือการจำลองฟิสิกส์ระดับภาพยนตร์ มือ มีด และการเทเป็นแอนิเมชัน stylized ไม่ใช่การหั่นอาหารจริง หากต้องการสมจริงแบบวิดีโอต้นแบบต้องแทนที่ด้วย asset แบบโปร่งใสและ/หรือ frame sequence ที่เตรียมอย่างถูกต้อง

## ไฟล์ที่แนะนำให้เตรียมในขั้นภาพสมจริง

| `assets/avocado-whole.webp` | อะโวคาโดลูกเดียวไม่มีพื้นหลัง | WebP/PNG alpha; 800x1000 ขึ้นไป |

| `assets/avocado-half-empty.webp` | อะโวคาโดครึ่งไม่มีเมล็ด | WebP/PNG alpha; 800x1000 |
| `assets/avocado-slice.webp` | ชิ้นสไลซ์เดี่ยว ไม่มีพื้นหลัง | WebP/PNG alpha; 400x600 |
| `assets/salad-without-avocado.webp` | จานสลัดที่ยังไม่ใส่อะโวคาโด | WebP/PNG alpha; 1800x1400 |

| `assets/pouring-frames/` | ฉากมือ/ภาชนะเทสไลซ์ | มีได้ถ้าต้องการความสมจริงสูง; อาจใช้ชิ้นสไลซ์แยกกับ Motion Path แทน |

**สำคัญ:** ภาพแต่ละชิ้นต้องไม่มีพื้นหลังและไม่มีอวัยวะหรือวัตถุอื่นติดมาถ้าต้องแอนิเมตแยก; รูปเขียง มือ และอาหารต้องใช้มุมกล้อง แสง และทิศทางเดียวกัน เลือก top-down หรือ 3/4 แบบใดแบบหนึ่งทั้งฉาก

**หากต้องประหยัดเวลาจริง ๆ:** เริ่มจากภาพรวม 7 ชิ้น ได้แก่ กิ่งไม้, ผลเต็มลูก, เขียง, ซีกมีเมล็ด, ซีกไม่มีเมล็ด, ชิ้นสไลซ์, จานสลัดเปล่า แล้วเพิ่มชุดเฟรมมือหั่นเมื่อพร้อม

## วิธีเชื่อมเข้ากับ Antigravity

1. สร้างโปรเจกต์ใหม่ แทนเว็บกรีกโบราณ (อย่าผสม Hero เดิม)
2. นำ `index.html` ไปเป็นต้นแบบแรก หรืออัปโหลด ZIP นี้ให้ Agent ดู
3. วางคำสั่งจาก `ANTIGRAVITY_PROMPT_TH.txt` ให้ Agent ทำงานต่อ
4. เปลี่ยน SVG placeholder เป็น assets ที่เตรียมไว้ โดยรักษา scroll timeline และ HTML semantics
5. ให้ Agent ทดสอบในเบราว์เซอร์จริงที่ 0/25/50/75/100% ทั้งเดสก์ท็อป มือถือ และย้อนกลับ

## จุดแก้ไขในโค้ด

- สี: ตัวแปร CSS ใน `:root`
- ชื่อร้าน/ข้อความ: `<header>`, `.scene-copy`, `.below`, `<footer>`
- จังหวะการเคลื่อนไหว: ฟังก์ชัน `draw()` ใน `<script>` และตัวแปร `--tree-fall`, `--board-drop`, `--knife-drop`, `--reveal`, `--split`, `--pour`
- LINE ร้าน: เปลี่ยนค่า `STORE.lineUrl` ใน `<script>` เป็น URL LINE ที่ยืนยันแล้ว
- สินค้า: แก้ `.product` ทั้งสามรายการเป็นสินค้าจริงและราคา/สต็อกจริงภายหลัง

## เกณฑ์รับงาน (Definition of Done)

- เลื่อนลง: เห็นผลร่วงจริงในฉาก 1 ไม่ใช่เปลี่ยนภาพทันที
- ฉาก 2: ผลตกเขียงก่อนมือและมีดผ่า; แยกซีกหลังมีดผ่า (ไม่ใช่ผลสองซีกโผล่มาพร้อมผลเต็ม)
- ฉาก 3: สไลซ์หลายชิ้นร่วงลงและลงจาน ไม่ใช่เลื่อนภาพสลัดทั้งภาพ
- เลื่อนขึ้นย้อนเหตุการณ์กลับได้, เมนูข้ามฉากและปุ่มสินค้าใช้งานได้
- ไม่มีภาพขาด ไม่มีพื้นหลังแข็งติดกับ assets และไม่มีการยืด PNG แบบเสียรูป
- Desktop 1440x900 และ Mobile 390x844 ไม่ล้นแนวนอน
- เชื่อม LINE หลังผู้ใช้แจ้งลิงก์จริงเท่านั้น และไม่อ้างว่ารับชำระเงินได้หากยังไม่ได้เชื่อมระบบ

## สถานะการตรวจสอบ

ใช้เบราว์เซอร์ Headless Chromium ทดสอบว่า HTML แสดงบน Desktop/Mobile, ไม่มี JavaScript page error, ตัวแปร animation เปลี่ยนตาม scroll, และแสดงฉาก 3 ฉากได้ แต่ยังไม่ได้ตรวจการสั่งซื้อกับระบบ LINE จริง เพราะยังไม่มี URL ร้านจริง
